# ڕێبەری پەروەردەی شارباژێڕ — ئەکاونت و بەڕێوەبردن (Netlify)

## پێکهاتە
- `public/index.html` — پەیجی گشتی (ڕێبەر)، PWA
- `public/admin.html` — پەیجی بەڕێوەبردن (چوونەژوورەوە)
- `netlify/functions/api.mjs` — API: ئەکاونت، دەسەڵات، داتا (Netlify Blobs)
- `netlify/functions/units.json` — ناوی ١٩ هۆبەی دیوان
- `netlify.toml`, `package.json`

## دەسەڵات
- **هۆبەی پلان:** هەموو شتێک: هەموو هۆبەکان، ئەکاونتەکان، پرسیارە باوەکان.
- **هەر هۆبەیەکی تر:** تەنها زانیاری هۆبەی خۆی (ئەرک، ژوور، کاتی دەوام، تەلەفۆن، ئیمەیڵ).

## دامەزراندن (یەکجار)
1. ئەم فۆڵدەرە لە Git (GitHub) بار بکە و لە Netlify ـدا "Import from Git" بکە.
   (Netlify Drop بۆ function و npm install باش نییە.)
2. Site settings ← Environment variables:
   - `AUTH_SECRET` — نووسراوێکی درێژ و تایبەت (لانیکەم ٣٢ پیت)
   - `SETUP_KEY` — کلیلێکی یەکجار بۆ دروستکردنی ئەکاونتی پلان
3. Deploy بکە، پاشان `/admin.html` بکەوە. ئەگەر ئەکاونت نەبوو، فۆرمی ڕێکخستنی سەرەتا دەردەکەوێت:
   کلیلی دامەزراندن + ناو + وشەی نهێنی بۆ هۆبەی پلان.
4. بە هۆبەی پلان بچۆ ژوورەوە، لە بەشی «ئەکاونتەکان» ئەکاونتی هەر هۆبەیەک دروست بکە.

## نوێکردنەوە
ئەکاونت و داتا لە Netlify Blobs هەڵدەگیرێن، بۆیە نوێکردنەوەی کۆد ئەوانە ناسڕێتەوە.
ئەگەر فایلی `public/index.html` گۆڕدرا، لە `public/sw.js` ـدا `VERSION` بگۆڕە.

## تێبینی ئاسایش
- وشەی نهێنی بە PBKDF2 (SHA-256، ٢١٠ هەزار جار) هەڵدەگیرێت، و هیچ جارێک بە ڕووندەقی نایەتە ناو داتا.
- نەهێنی `AUTH_SECRET` تەنها لە Netlify ـدایە و نابێت لە کۆدەکەدا بنووسرێت.
- هەموو زانیاریی گشتی (ڕێبەر، پرسیارەکان) بە کراوەیی دەخوێنرێنەوە؛ زانیاری تاکەکەسی (مۆبایلی فەرمانبەران) لەم ئەپەدا نییە.
- ئەمە پێویستی بە تاقیکردنەوەی ڕاستەقینە هەیە لە Netlify؛ لەم ژینگەیەدا تەنها پشکنینی syntax کراوە.
